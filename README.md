# 🛍️电商系统 

## 概述

本项目采用Spring Boot进行后端开发，前端分为中后台管理系统与前台用户界面。该项目旨在提供一个全面且高效的电子商务解决方案，涵盖商品管理、用户管理、权限控制等核心功能，并通过现代技术栈确保系统的高性能和可扩展性。

## 主要功能

### 🖥️后台管理功能 

- **⚙️角色管理**：灵活的角色分配与权限设置 
-  👤**用户管理**：用户的创建、编辑与删除操作
- 📋**菜单管理**：菜单项的配置与维护 
- **🛒商品管理**：商品信息的添加、修改及查询
- **🔖品牌管理**：品牌的增删改查
- **🗂️分类管理**：产品分类的组织与调整
- 📜**日志管理**：记录并查看系统操作日志 

### 🌐前台功能 

- **🔐用户登录注册**：支持新用户的注册以及已有用户的登录服务 

### 💡拓展功能 

- **🔒Redis用户权限管理**：利用Redis实现高效、实时的权限验证与管理 
- **🗄️MinIO文件存储**：安全可靠的大规模文件存储方案 
- **📄Excel文件处理**：使用easyExcel轻松完成Excel文件的导入导出任务
